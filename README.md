# Background Remover

Công cụ xóa nền ảnh PNG/JPG chạy **100% trên trình duyệt**. Giao diện Material 3 Expressive, tham khảo từ [messenger-e2ee-count](https://github.com/dangphuc2470/messenger-e2ee-count).

## Tính năng

- Hỗ trợ **PNG** và **JPG**
- Tải ảnh bằng kéo thả, chọn file hoặc dán (Ctrl+V)
- Chọn màu nền cần xóa (tên màu hoặc hex)
- Điều chỉnh độ nhạy màu (%)
- Chỉ xóa vùng ngoài (flood fill từ cạnh)
- Làm mịn viền
- Xem trước mặt nạ hai màu
- Xuất PNG trong suốt / sao chép clipboard
- Xử lý qua Web Worker — UI luôn mượt

## Cài đặt

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
